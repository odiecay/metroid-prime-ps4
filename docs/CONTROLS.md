# PS4 controls

Pick the layout that feels right: original-style face buttons with twin-stick
aim, or the Modern preset with trigger-based shooting. Both use PlayStation
prompts and DualShock 4 vibration, and both can be remapped in the port settings.

**Options** pauses the game. **Hold the touchpad button for about 0.8 seconds**
to open or close the port's settings. Share and the PS button keep their PS4
system functions.

## Original-style buttons with twin-stick aim

With the original button layout and **Twin Stick Aim** enabled:

| Control | Action |
|---|---|
| Left stick | Move |
| Right stick | Aim |
| Cross | Fire; hold to charge when the Charge Beam is available |
| Circle | Jump |
| Square | Enter or leave Morph Ball |
| Triangle | Missile; Power Bomb in Morph Ball when available |
| L2 | Lock on; hold to scan a target with the Scan Visor selected |
| R1 | Map |
| D-pad | Select visor |
| Hold L1 + D-pad | Select beam |
| Options | Pause / inventory |

You need to collect the relevant beams, visors and Morph Ball upgrades before
their actions are available. In Morph Ball, fire places bombs and jump activates
the Boost Ball once obtained.

### Beams and visors

| Direction | Visor | Beam while holding L1 |
|---|---|---|
| Up | Combat | Power |
| Left | Scan | Plasma |
| Down | Thermal | Ice |
| Right | X-Ray | Wave |

These directions describe the original layout. Remapping or swapping Scan and
X-Ray changes them; the in-game prompts follow your selected bindings.

## Modern layout

For trigger-based shooting, open the port settings and choose
**Controls → Remap → Presets → Modern**. This layout uses:

| Control | Action |
|---|---|
| Left / right stick | Move / aim |
| R2 | Fire; hold to charge |
| L2 | Lock on / scan |
| Cross | Jump |
| Circle | Morph Ball |
| R1 | Missile / Power Bomb |
| Triangle | Map |
| D-pad / hold L1 + D-pad | Visors / beams |
| Options | Pause |

Changing a preset replaces the gameplay bindings. You can make individual
changes under **Controls → Remap**. The settings shortcut remains a touchpad
hold.

## Adjusting the feel

The port settings include aim sensitivity, camera inversion and stick/trigger
deadzones. Twin-stick aim can be switched off for the original GameCube-style
camera and right-stick beam selection. Menu navigation uses the D-pad or stick,
with Cross to confirm and Circle to go back under the standard menu-button
setting.

The game has DualShock 4 vibration. Disconnecting and reconnecting the controller
doesn't require a keyboard. Save your progress at a save station before ending
a session.

For installation and updates, see [Getting started](INSTALLING.md). For the
native input path behind these controls, see [How it works](TECHNICAL.md#making-it-feel-like-a-ps4-game).
